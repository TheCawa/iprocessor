# Недочёты
1. [FIXED] Сыплет предупреждениями о неизвестных опкодах. — Теперь ROM BIOS загружается автоматически, пользовательские программы грузятся в RAM (0x60000+), поэтому опкоды интерпретируются корректно.
2. [FIXED] VBUFFER почему-то занимает адресное пространство прямо по среди рабочей области памяти. — Добавлено VRAM-окно 0x00050000-0x0005FFFF с банковым регистром 0x00020007; физическая VRAM оставлена на 0x00100000. Пользовательская RAM теперь начинается с 0x00060000.
3. [FIXED] Неудобный просмотр содержимого памяти. — Добавлены кнопки Page Up / Page Down для прокрутки дампа на страницу (256 байт).
4. [FIXED] Отсутствует возможность редактирование содержимого памяти. — Двойной клик по байту в дампе памяти открывает поле ввода для редактирования.
5. [FIXED] Отсутствует отображения названия вставленного образа диска в списке Drive#0-#3. — В меню SYSTEM теперь отображается имя файла для каждого Drive, добавлена кнопка Eject.
6. [FIXED] Отсутствует возможность настройки аппаратного разрешения экрана. — В меню SYSTEM добавлен выпадающий список Screen mode (80x25, 40x30, 80x60, 80x30 8x16, графические 320x200/240/640x480/800x600).
7. [FIXED] Необходимо сделать ROM BIOSа по умолчанию. — Эмулятор теперь всегда загружает BIOS по 0x00000000. Пользовательские программы загружаются в RAM. Добавлен аргумент --bios для явного выбора ROM.
8. [FIXED] После выхода или закрытия эмулятора не хватает сохранения состояния машины. — В меню FILE добавлены Save state... / Load state... (*.ips).
9. [FIXED] Беспорядок в регистрах. — Для i80148 добавлен кастомный ImGui-рендер регистров в стиле R0/EX/A0-A7/IX/IY/SP/BP/IC/FL/IDTR.
10. [FIXED] Добавь возможность сброса содержимого ОЗУ. — В меню SYSTEM добавлена кнопка Clear RAM, очищающая только пользовательскую область памяти (user_ram_start..end).
11. [FIXED] Убрать растяжение шрифта текстового режима по высоте. — Режим 0x12 (80x30) теперь использует нативный 8x16 шрифт, сгенерированный из 8x8.
