
	-# Byte order = BIG ENDIAN
	-# Registers = 36
	-# Among them: 
	-#	1 zero (r0), 
	-#	21 GPR (7 Dword EX1-EX7, 7 Word X1-X7, 7 Byte XL1-XL7), 
	-#	1 IC (Instruction counter), 
	-#	1 FL (Flags),
	-#	1 SP (Stack pointer) & 1 BP (Base pointer),
	-#	2 Index registers (IX - Source, IY - Destination),
	-#  8 Additional registers (A0-A7, can be used as address register, or additional GPRs).
	-#  1 Interrupt descriptor table register (IDTR)
	
	-# Data address bus: 		 32 bit (4GB; 4096MB); 
	-# Instructions address bus: 32 bit (4GB; 4096MB); 
	-# Input data bus: 			 32 bit (4 Bytes);
	-# Output data bus:			 32 bit (4 Bytes);
	-# Input instructions bus: 	 64 bit (8 Bytes);
	-# Memory model: 			 Flat;
	-# Memory addressing modes:  Flat (imm32), Index (Base:Offset), Indirect (reg), 
								 Index-disp (Base:Offset:disp), Relative-disp (Base:Offset:disp);
	-# Insts. addressing modes:  Flag (IC=imm32), Relative (IC+imm32), Indirect (IC=reg).

	17h - FL	1Ah - IX	1Dh - A1	20h - A4	23h - A7
	18h - SP	1Bh - IY	1Eh - A2	21h - A5	24h - IDTR
	
	Register file out ABI:
	A - ALU_A, DATA_OUT
	B - ALU_B, SRC_ADDR

	#ID - #BIN - #NAME	 - #LE0 #LE1 #LE2 #LE3
	00h - 0000 - Byte	 -  n    n    n    y
	01h - 0001 - Word    -  n    n    y    y
	02h - 0010 - Dword   -  y    y    y    y
	03h - 0011 - Qword X -  x    x    x    x
	04h - 0100 - REG     -  ?    ?    ?    ?
	
	-# REG is mode lookup table
	
	-# LEGEND:
	-# LEn - MEM Line enable
	-# n - no; 
	-# y - yes; 
	-# x - not made; 
	-# ? - depends on the mode.
