Specs:
	CPU - i80148
	RAM - 16M (up to 4096M)
	
Memory regions:
    BANK 0000h:
    #START    - #END      - #MB - #NAME   
    
    00000000h - 0000FFFFh - 00h - BIOS/VBIOS ROM
    00010000h - 0001FFFFh - 00h - CMOS
    00020000h - 0002FFFFh - 00h - MMIO
    00030000h - 0003FFFFh - 00h - DEVICE CALLS
    00040000h - 0004FFFFh - 00h - BIOS RAM
    00050000h - 0005FFFFh - 00h - VRAM WINDOW (64 KB view into separate VRAM)
    00060000h - FFFFFFFFh - 00h - USER RAM
    
    VRAM: separate video memory, size configurable (default 512 KB). The CPU sees it
    through the VRAM WINDOW at 0x00050000..0x0005FFFF. The base offset inside VRAM is
    selected by TERM_BUFFER (0x00020070). The video card reads the same VRAM at the
    same TERM_BUFFER offset.

	BANK 0003h-FEFFh - Other

IRQ:
	0x20 - TIMER
	0x21 - KEYBOARD
	0x22 - MOUSE
	
	-# Exceptions are delivered through the IDT like regular interrupts.
	-# Vector is calculated as IDTR + (vector << 2).

Device classes:
	00h - System
	01h - Storage
	02h - Input
	03h - Timer
	04h - RTC
	05h - Video
	06h - RNG
	07h - FPU
	08h - Audio (PSG)
	FFh - Unknown
	
Device vendors:
	00h - None
	01h - System
	
Disk controller commands (DISK_CTRL):
	00h - Idle / reset
	01h - Acknowledge ready
	02h - Read single sector
	03h - Read multiple sectors (DISK_COUNT)
	04h - Write single sector
	05h - Write multiple sectors (DISK_COUNT)
	08h - Write DISK_DIN dword into sector buffer at BUFFER_OFFSET
	10h - Format (zero-fill DISK_COUNT sectors starting at DISK_LBA)

Disk status bits:
	Bit 0 - BUSY
	Bit 1 - ERROR

Video cards (selectable via emulator GUI or --vc command line option):
	"default"      - Combined text/graphics card, mode selected by VC_MODE
	"default-text" - 80x25 16-color text mode only
	"default-mono" - 80x25 green-phosphor monochrome text mode only

Video card "default" modes (selected by VC_MODE 0002001Ah):
	00h - 80x25 text, 8x8 font, 16-color VGA palette (640x200)
	01h - 320x200 256-color graphics (legacy Mode 13h-like)
	10h - 40x30 text, 8x8 font, 16 colors (320x240)
	11h - 80x60 text, 8x8 font, 16 colors (640x480)
	12h - 80x30 text, 8x8 font stretched to 8x16, 16 colors (640x480)
	20h - 320x240 256-color graphics
	21h - 640x480 256-color graphics
	22h - 800x600 256-color graphics


FPU operation codes (write to FPU_OP to execute):
	00h - ADD	01h - SUB	02h - MUL	03h - DIV
	04h - SQRT	05h - MIN	06h - MAX	07h - CMP
	10h - ITOF (int32 A -> float result)
	11h - FTOI (float A -> int32 result bits in RESULT)
	12h - UTOF (uint32 A -> float result)
	13h - FTOU (float A -> uint32 result bits in RESULT)
	20h - SIN	21h - COS	22h - TAN	23h - COT
	24h - LOG	25h - EXP

FPU flags (FPU_FLAGS):
	bit 0 - ZERO	bit 1 - SIGN	bit 2 - DIV0	bit 3 - INVALID
	bit 4 - GT (cmp A>B)	bit 5 - EQ (cmp A==B)	bit 6 - LT (cmp A<B)

PSG usage notes:
	- Sample rate 44100 Hz, mono, 16-bit, SDL2 audio callback.
	- Tone period value = (sample_rate / (2 * desired_frequency)).
	  Example: for 440 Hz use period = 44100 / (2*440) ~= 50.
	- Mixer bits 0-2 enable tone for channels 0-2; bits 3-5 enable noise.
	- Volume register bit 7 set replaces channel volume with envelope level.
	- Envelope shapes: 0=off, 1=attack (0->15), 2=decay (15->0),
	  3=triangle (0->15->0 looping), 4=sawtooth (0->15 looping).

RNG usage notes:
	- Reading RNG_RAND advances the generator and returns the next value.
	- Writing RNG_SEED reseeds the generator for reproducible sequences.

Disk image support:
	- Disk images can be .bin, .hex or .img.
	- .bin and .img are treated as raw sector images.
	- .hex is parsed as Logisim/simple hex format.
