Device classes:
	00h - None
	01h - Disk controller
	02h - Reserved
	FFh - Unknown
	
Device vendors:
	00h - None
	
Device status:
	00h - Device is working properly
	01h - Unknown error
	
DISK CONTROL STANDART:
  Input:
	IX - Destination (read) / IY - Source (write)
	A0 - Address offset
	EX2 - LBA pointer
	EX3 - Amount of LBA
I	EX7 - Command
	A7  - Disk buffer offset
	
	-# IMPORTANT! A1 REGISTER RESERVED FOR STORAGE DEVICE CALL ADDRESS

  Return:
	EX1 - Disk output (read) / input (write)
	
	-# Address = IX + A0
	
DEVICE CALLS:
	#N  - #Description
	
	00h - Reserved
	01h - Read sector
	02h - Write sector
